【任务】识别小说章节标题并生成标准化映射表

【输入】
以下是某小说中提取的所有疑似章节标题行（每行代表一个标题）：
---
{{candidate_lines}}
---

【要求】
1. 识别哪些是真实的章节标题，哪些是误提取的正文
2. 对真实章节标题，按原文顺序分配新编号（从1开始）
3. 输出 JSON 格式的映射表

【输出格式】
必须用 Markdown 代码块包裹 JSON，格式如下：

{
  "book_name": "{{book_name}}",
  "mapping": [
    {"original": "第一章 初入江湖", "new": "第1章"},
    {"original": "第2章 风云再起", "new": "第2章"}
  ],
  "total_chapters": 35,
  "skipped": ["误提取的行1", "误提取的行2"]
}

【约束】
- 编号必须连续，从1开始
- 只输出代码块，不添加任何额外解释
- 如果某行明显不是章节标题，放入 skipped 数组
- 特殊章节（序章、楔子、尾声、后记、番外）保留原名，不参与编号
